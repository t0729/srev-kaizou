# リアルタイム地震ビューアー改造版  
リアルタイム地震ビューアーを改造したものです。  
[ここ](http://srev-s.f5.si/)で使用できます。

改造版に関する問題・不具合等について、本家のIssue・サポート等へ問い合わせる行為は、**絶対に**行わないでください。  
本家の製作者様の負担増加につながるため、**非常に迷惑**となります。
## 情報の取得元
緊急地震速報：[Wolfx Open API](https://wolfx.jp/docs/open-api)  
噴火情報：[気象庁防災情報XMLフォーマット形式電文の公開](https://xml.kishou.go.jp/xmlpull.html)  
海底震度：[海洋状況表示システム](https://www.msil.go.jp/map/ja/?locale=ja)  
台湾リアルタイム震度：[ExpTech API](https://exptechtw.github.io/)
